# Лицензии ассетов звука — «Утка Разраба»

Все 5 пресетов получены из записей на Wikimedia Commons (CC BY-SA 3.0/4.0, атрибуция обязательна).
Обработка: вырезка фрагмента ~0.9 с наибольшей энергией, нормализация, WAV PCM 16-bit mono 44100 Гц.
В приложении атрибуция выводится на экране «О приложении» → «Звуки» (ATR-01), данные берутся из `sound_catalog.json`.
